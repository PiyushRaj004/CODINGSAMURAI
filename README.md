
  # CODING SAMURAI INTERNSHIP TASK

## Data Science Internship

This repository contains the projects completed as part of my Data Science Internship at Coding Samurai.

The projects cover data analysis, data visualization, machine learning, and time series forecasting using Python and related libraries.

---

## Projects

### Project 1 – Sales Data Analysis
**Level:** Beginner

- Analyzed retail sales data using Python.
- Performed basic data cleaning and descriptive analysis.
- Created visualizations to understand sales trends and patterns.
- Used Pandas, Matplotlib, and Seaborn.

---

### Project 2 – Linear Regression on Sales Data
**Level:** Beginner

- Built a Linear Regression model to predict sales.
- Performed data preprocessing and exploratory analysis.
- Used Python and Scikit-learn.
- Evaluated model predictions using regression metrics.

---

### Project 3 – Titanic Exploratory Data Analysis
**Level:** Intermediate

- Performed Exploratory Data Analysis on the Titanic dataset.
- Analyzed missing values and passenger characteristics.
- Studied relationships between features such as age, gender, passenger class, and survival.
- Created visualizations using Matplotlib and Seaborn.

---

### Project 5 – Stock Price Forecasting Using ARIMA
**Level:** Advanced

- Analyzed historical Apple (AAPL) stock price data from 2020 to 2024.
- Performed time series analysis and data preprocessing.
- Used the Augmented Dickey-Fuller (ADF) test to analyze stationarity.
- Applied first-order differencing.
- Built an ARIMA(5,1,0) forecasting model.
- Evaluated the model using MAE and RMSE.
- Generated a 30-trading-day stock price forecast.
- Used Python, Pandas, NumPy, Matplotlib, Statsmodels, and Scikit-learn.
