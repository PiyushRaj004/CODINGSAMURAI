# Linear Regression - Sales Prediction

## Project Overview

This project uses Linear Regression to predict Sales based on Advertising spend.

## Objective

The goal is to understand the relationship between advertising investment and sales and build a simple machine learning model for sales prediction.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Steps

1. Created and loaded the dataset
2. Explored the data
3. Visualized the relationship between Advertising and Sales
4. Split the data into training and testing sets
5. Built a Linear Regression model
6. Generated Sales predictions
7. Evaluated the model using R² Score and MAE
8. Visualized Actual vs Predicted Sales

## Model Performance

- R² Score: 0.99985
- Mean Absolute Error: 0.28

## Key Insights

- Advertising spend has a strong positive relationship with Sales.
- The Linear Regression model performed very well on this dataset.
- Higher advertising spend is associated with higher Sales.
