# CODING SAMURAI – Data Science Internship

This repository contains the projects completed as part of my Data Science Internship at Coding Samurai.

## Projects

### 1. Titanic Exploratory Data Analysis (EDA)

Performed exploratory data analysis on the Titanic dataset to understand passenger information and survival patterns.

**Key Analysis:**
- Dataset structure and basic statistics
- Missing value analysis and data cleaning
- Survival distribution
- Survival based on gender
- Survival based on passenger class
- Age group and survival relationship
- Data visualizations using Seaborn and Matplotlib

### 2. Titanic Survival Prediction using Logistic Regression

Built a Logistic Regression model to predict whether a passenger survived the Titanic disaster.

**Steps Performed:**
- Data preparation
- Feature selection
- Handling missing values
- Train-test split
- Logistic Regression model training
- Model prediction
- Accuracy evaluation
- Classification report
- Confusion matrix

**Model Accuracy:** 81%

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
